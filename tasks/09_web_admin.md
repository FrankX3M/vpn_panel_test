# ТЗ 09 — Web Admin UI

**Контракт:** `contracts/09_web_admin.md`
**Зависимости:** `06_api_users_crud`, `08_client_links`
**Файлы:** `src/web/routes.py`, `src/web/templates/{base,index,new_user,user_detail}.html`, `src/web/static/style.css`, `tests/web/test_routes.py`

## Задача

Реализовать три страницы через Jinja2 (`fastapi.templating.Jinja2Templates`), опираясь напрямую на
сервисные функции/модели, а не на HTTP-вызовы к своему же API. Минимальная адаптивная вёрстка одним
CSS-файлом, без JS-фреймворков (можно немного ванильного JS для кнопки копирования ссылки).

## Критерии приёмки

- [ ] `GET /` рендерит список всех пользователей с текущим статусом и кнопками действий.
- [ ] `GET /users/new` → форма с одним полем `label`.
- [ ] `POST /users/new` → создаёт юзера (переиспользуя логику ТЗ 06), редиректит на `/users/{id}` (303).
- [ ] `GET /users/{id}` → показывает все доступные ссылки (только те, для которых `08_client_links`
      вернул не `None`) и QR-код на каждую, кнопки "выключить"/"включить"/"удалить".
- [ ] Страница читаема при ширине вьюпорта ~375px (мобильный) — проверить вручную, не только тестом.
- [ ] `ruff`/`mypy` проходят; для вёрстки строгий `mypy` на HTML не применяется, но Python-код
      маршрутов — да.
