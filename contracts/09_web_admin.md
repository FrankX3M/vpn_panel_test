# Контракт 09 — web_admin

Файлы: `src/web/routes.py` + `src/web/templates/*.html` (Jinja2). Опирается на `06_api_users_crud`, `08_client_links`.

## Страницы

```
GET  /                → список пользователей (label, статус, кнопки вкл/выкл/удалить)
GET  /users/new        → форма создания
POST /users/new         → создаёт, редиректит на /users/{id}
GET  /users/{id}         → карточка юзера: три ссылки + QR-код на каждую, кнопка вкл/выкл/удалить
```

## Инварианты

- Веб-слой — тонкая обёртка над `api/users.py`, не дублирует бизнес-логику (вызывает те же функции/эндпоинты, что и REST API — либо напрямую импортирует сервисные функции, а не ходит на себя же по HTTP).
- Никакой отдельной аутентификации внутри FastAPI — весь Basic Auth на уровне Caddy (контракт `04_render_caddy`), приложение считает, что если запрос дошёл до 127.0.0.1:8000, он уже авторизован.
- Минимальная вёрстка — один CSS-файл без фреймворков, страница должна быть читаема на телефоне (админ может открывать с телефона).
